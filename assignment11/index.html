How This Advisor Works

Course information is stored in an external JSON file. JavaScript loads the data and dynamically creates the course cards, checkboxes, descriptions, and planning controls.

The advisor supports AND prerequisites, OR prerequisites, and mutually exclusive course alternatives.

User interactions trigger JavaScript events that update course eligibility and the semester plan without reloading the page.
