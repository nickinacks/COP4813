Assignment 11

For Assignment 11, I created an interactive BSIT Course Advisor using HTML5, CSS, JavaScript, and JSON. The advisor dynamically generates course cards and checkboxes from an external JSON database. Students can mark courses they have completed, check which classes they are eligible to take based on AND/OR prerequisites, and view detailed advising notes. Students can also create a semester course plan using buttons or drag-and-drop. The application handles mutually exclusive course alternatives and automatically updates progress counters and planned credit totals.
