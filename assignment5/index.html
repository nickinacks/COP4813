Interactive Spirograph

Enter values for the outer circle radius, inner circle radius, and pen offset. Then select Start Spirograph to draw the pattern using the HTML5 Canvas and JavaScript.

Spirograph Equations

x = (R + r) × cos(t) - (r + O) × cos(((R + r) / r) × t)

y = (R + r) × sin(t) - (r + O) × sin(((R + r) / r) × t)

R = radius of the outer fixed circle
r = radius of the rotating inner circle
O = offset of the pen from the center of the inner circle
