Project Overview

The objective of Assignment 10 was to create a mobile-friendly version of my COP4813 homepage and evaluate its performance, accessibility, best practices, and search engine optimization.

I used responsive CSS media queries, flexible layouts, scalable images, and touch-friendly navigation to ensure the homepage works on both mobile devices and desktop computers.

Accessibility Analysis

Lighthouse Accessibility Score: 100/100

The accessibility audit evaluates automated checks related to how people with different abilities can interact with a website.

My homepage uses descriptive image text, semantic HTML elements, visible navigation, readable content, and keyboard focus styling.

Figure 3: Accessibility audit results and manual checks.

Analysis: The homepage received a perfect score on the automated accessibility checks. However, Lighthouse also recommends manual testing of keyboard navigation, logical tab order, focus behavior, and screen-reader compatibility.

A score of 100 does not guarantee that every accessibility requirement has been met, so manual testing remains an important future step.

Mobile-Friendly Design Improvements

To improve the mobile experience, I made several changes to my existing CSS stylesheet:

  • Added responsive breakpoints for tablets and smartphones.
  • Changed the navigation menu to a vertical layout on smaller screens.
  • Increased navigation link sizes for touchscreen use.
  • Made images resize to fit different screen widths.
  • Adjusted spacing and padding for smaller displays.
  • Improved keyboard focus indicators for accessibility.
  • Preserved the same menu options and homepage features on desktop and mobile devices.

Conclusion

Assignment 10 helped me understand the importance of responsive design and testing websites with modern browser development tools.

By updating the CSS and testing the published homepage using Google Lighthouse, I was able to evaluate how well the website performs on mobile devices.

The homepage achieved scores of 100 in Performance, Accessibility, Best Practices, and SEO during the mobile Lighthouse audit. Although the results were excellent, additional manual accessibility and security testing could help identify issues not covered by automated scoring.
