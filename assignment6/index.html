About the Data

The cybersecurity incident information displayed below is stored in a separate incidents.json file.

JavaScript uses the Fetch API to retrieve the JSON file, parse the data into JavaScript objects, and create the table automatically.

Because the data is stored separately from the HTML, the JSON file can be updated without changing the structure of this webpage.
