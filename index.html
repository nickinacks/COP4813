Interactive BSIT Course Advisor created using HTML5, CSS, JavaScript, and JSON. The application dynamically generates course cards and checkboxes from a JSON database. Students can mark completed courses, determine which classes they can take next based on AND/OR prerequisites, and review detailed course advising notes. The advisor also supports mutually exclusive course alternatives and allows students to create a semester plan using buttons or drag-and-drop functionality.
